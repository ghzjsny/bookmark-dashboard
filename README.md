# 书签导航 · Bookmark Dashboard

一个 Chrome 新标签页书签扩展（MV3）。读取本机书签，生成清爽的导航面板。

## 功能

- 书签网格：打开新标签页即见书签，点击直达
- 底部 Dock 常驻栏：最多固定 10 个常用网站，独占底部一行
- 清爽模式：点右上角叶子图标进入极简壁纸 + 居中搜索界面
- 一键获取图标：智能抓取站点 favicon，多源兜底，无网回退首字母色块
- 搜索引擎切换 + `Ctrl/⌘ + K` 聚焦搜索
- 浅色 / 深色主题、自定义壁纸与蒙版深度，设置项自由开关
- 本地优先：书签与图标仅存本机，不上传任何服务器

## 安装

方式一（推荐个人使用）：
1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本仓库根目录
4. 打开新标签页即可使用

方式二：下载 `bookmark-dashboard.crx`，在开发者模式下拖入 `chrome://extensions` 安装。

